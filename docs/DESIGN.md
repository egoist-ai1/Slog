# Дизайн-система «Слог»

## Характер

Рабочий инструмент, который почти не виден: тёмная капсула у края экрана, один акцент, спокойное движение. Внимание привлекает только голос (лента), всё остальное приглушено. Ориентир по проработке: Linear, Raycast, Arc. Стиль не копируется.

Решения владельца (06.10.2026–07.10.2026): капсула вариант C, затем детализированный спектр вместо ленты, акцент насыщенный лайм, имя «Слог», знак без букв, полностью лаймовый диск микрофона с чёрной иконкой.

|---|---|---|

| Фон окон | `#08080A` | `#F6F6F8` |
| Поверхность | `#101014` | `#FFFFFF` |
| Граница | `#2A2A30` | `#D7D7DD` |
| Текст / приглушённый | `#F7F7F8` / `#A3A3AA` | `#18181B` / `#5F6069` |
| Hover / pressed / выбор | `#1D2809` / `#2A3A0B` / `#2A3A0B` | `#F1F9DD` / `#E2F2B9` / `#E2F2B9` |

Капсула всегда чёрная (`#000`) в обеих темах, поэтому её внутренности используют фиксированный лайм, а не тему. Токены: `Themes/Dark.xaml`, `Themes/Light.xaml`, `Themes/HighContrast.xaml` (системные цвета, без акцента).

## Капсула

- **Размер** 256×48, радиус по высоте, пиксельная граница (`PixelPerfectCapsuleBorder`).
- **Слушаю**: диск микрофона (лайм, чёрная иконка) · лента голоса · таймер (приглушённый) · отмена.
- **Распознаю**: диск · подпись · три точки с каскадом.
- **Вставлено**: лаймовая галочка · подпись. Ошибка: янтарный значок (`#F59E0B`, контраст на чёрном 9,8:1) и текст причины.
- **Спектр** (`Controls/CapsuleWaveform.cs`): 44 зеркальных столбика шириной 58% ячейки с закруглением, светлые торцы, падающие пиковые риски (0,55 px за кадр), тонкий контур по вершинам (Безье) и ось на тишине. 15 полос спектра интерполируются по столбикам, медленная фаза даёт мелкую структуру. Высокий контраст: простые столбики системного цвета. Прежняя «лента» с эхо-слоями отвергнута владельцем как расплывчатая и шумная.

## Движение

| Событие | Длительность | Кривая |
|---|---|---|
| Появление капсулы | 90 мс: прозрачность 0→1, масштаб 0,94→1, сдвиг по Y 6→0 | ease-out (кубическая) |
| Уход | 140 мс: прозрачность →0, масштаб →0,96, сдвиг по Y →4 | ease-in |
| Смена состояния: контент / диск | 160 мс / 180 мс | ease-out |
| Кольцо «можно говорить» | 280 мс, масштаб 1→1,6, прозрачность 0,35→0 | ease-out |
| Ширина капсулы: раскрытие под волну | 160 мс, перелёт до 2 % | ease-out, затем ease-in-out |
| Ширина капсулы: остальные смены | 210 мс | квинтическая ease-out |
| «Уменьшить движение»: вход и уход | 80 мс, только прозрачность | линейно |
| Лента: атака / спад | 10 мс / 115 мс | экспоненциальное сглаживание |

Блика по ленте нет: движение ленты задают только уровень голоса и медленная фаза. Фон капсулы (`PixelPerfectCapsuleBorder`) растеризуется один раз на DPI, высоту и кисти: два торца и столбец середины, ширина в ключ кеша не входит и анимируется без повторной растеризации.

Частота: min(частота монитора, 144) Гц, определяется при показе, смене DPI и режима дисплея (`Services/DisplayRefresh.cs`, `Controls/Motion.cs`); на 60 Гц поведение прежнее. Фаза волны и падение пиков идут по реальному времени, а не по кадрам. В покое подписки на Rendering и активных Storyboard нет. Длительности и кривые - в `MotionTokens.xaml` (90/140/160/180/280/80 мс). Замер кадров: `EGOIST_VOICE_FRAME_STATS=1` пишет в лог p50/p95/p99 интервалов за сеанс показа. `prefers-reduced-motion` (настройка Windows): интенсивные эффекты заменяются спокойной сменой, смысл и состояния сохраняются.

## Правила

- Один акцент на вид; анимируем только прозрачность и трансформации; ничего не рисуется вне видимой области.
- Текст интерфейса: Segoe UI Variable / Segoe UI (кириллица проверена), иконки Segoe Fluent Icons.
- Контраст: основной текст ≥ 4,5:1, элементы ≥ 3:1 в обеих темах (светлая тема использует тёмный лайм `#4A8200`).
- Не проверено: работа на системном высоком контрасте с экранным диктором, 4K/масштаб выше 150%, частота кадров на 120/144 Гц на реальном мониторе (логика покрыта тестами, замер - по переменной выше); выигрыш от отказа от `AllowsTransparency` не доказан, окно оставлено прежним.

## Центр управления (27–28.10.2026)

- Главная: карточка «Готовность» (микрофон, распознавание, кнопка, автозапуск; действие у проблемной строки), блок «Последняя диктовка», «Поведение приложения». Выбор кнопки запуска — в сворачиваемом редакторе.
- Внешний вид: тема выбирается тремя плитками с миниатюрой окна (системная — половина тёмная, половина светлая); выбранная плитка с лаймовой рамкой 2 px. Цвета миниатюр фиксированы, это образцы тем.
- Текст: оба поля одной высоты (общие строки `SharedSizeGroup`), «Копировать» в заголовке каждого поля, действия Qwen — в одну строку.
- Размер содержимого окна считается от корневого Grid (`RootGrid_OnSizeChanged`), не от Viewbox; страницы вкладок одной ширины (`TabItem.HorizontalContentAlignment=Stretch`).
- Проверка вида: `Egoist.Voice.exe --render-settings-preview <png> <режим>` (`general`, `models`, `text-filled`, `appearance`, `history-filled`; префиксы `light-`, `contrast-`), рядом `.layout.json` с `fits`.
