# Дизайн-система «Слог»

## Характер

Рабочий инструмент, который почти не виден: тёмная капсула у края экрана, один акцент, спокойное движение. Внимание привлекает только голос (лента), всё остальное приглушено. Ориентир по проработке: Linear, Raycast, Arc. Стиль не копируется.

Решения владельца (06.10.2026): капсула «лента» (вариант C), акцент насыщенный лайм, имя «Слог», знак без букв, полностью лаймовый диск микрофона с чёрной иконкой.

## Токены

| Роль | Тёмная тема | Светлая тема |
|---|---|---|
| Акцент (заливка, иконки) | `#A8FF00` | `#4A8200` |
| Текст на акценте | `#0A0F00` | `#FFFFFF` |
| Фон окон | `#08080A` | `#F6F6F8` |
| Поверхность | `#101014` | `#FFFFFF` |
| Граница | `#2A2A30` | `#D7D7DD` |
| Текст / приглушённый | `#F7F7F8` / `#A3A3AA` | `#18181B` / `#5F6069` |
| Hover / pressed / выбор | `#1D2809` / `#2A3A0B` / `#2A3A0B` | `#F1F9DD` / `#E2F2B9` / `#E2F2B9` |

Капсула всегда чёрная (`#000`) в обеих темах, поэтому её внутренности используют фиксированный лайм, а не тему. Токены: `Themes/Dark.xaml`, `Themes/Light.xaml`, `Themes/HighContrast.xaml` (системные цвета, без акцента).

## Капсула

- **Размер** 256×48, радиус по высоте, пиксельная граница (`PixelPerfectCapsuleBorder`).
- **Слушаю**: диск микрофона (лайм, чёрная иконка) · лента голоса · таймер (приглушённый) · отмена.
- **Распознаю**: диск · подпись · три точки с каскадом.
- **Вставлено**: лаймовая галочка · подпись. Ошибка: янтарный значок и текст причины.
- **Лента** (`Controls/CapsuleWaveform.cs`): три слоя одной формы. Два эха отстают от тела, тело залито вертикальным градиентом (тёмный лайм по краям, светлый у оси), поверх бежит мягкий блик, на тихом звуке видна светлая ось. Форма строится по 8 полосам спектра, сглаженная Catmull-Rom. Высокий контраст: простые столбики системного цвета.

## Движение

| Событие | Длительность | Кривая |
|---|---|---|
| Появление капсулы | 250 мс | ease-out |
| Смена состояния (контент, диск) | 160–180 мс | decelerate |
| Лента: атака / спад | 10 мс / 115 мс | экспоненциальное сглаживание |
| Блик по ленте | непрерывно, ~1,6 с на проход | линейно |
| Уход | на 25% быстрее входа | ease-in |

Частота: при записи по частоте экрана (до 60 Гц), в покое анимации остановлены. `prefers-reduced-motion` (настройка Windows): интенсивные эффекты заменяются спокойной сменой, смысл и состояния сохраняются.

## Правила

- Один акцент на вид; анимируем только прозрачность и трансформации; ничего не рисуется вне видимой области.
- Текст интерфейса: Segoe UI Variable / Segoe UI (кириллица проверена), иконки Segoe Fluent Icons.
- Контраст: основной текст ≥ 4,5:1, элементы ≥ 3:1 в обеих темах (светлая тема использует тёмный лайм `#4A8200`).
- Не проверено: работа на системном высоком контрасте с экранным диктором, 4K/масштаб выше 150%, частота кадров на 144 Гц.
