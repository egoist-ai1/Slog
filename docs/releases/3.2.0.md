# Слог 3.2.0

Дата: 10.10.2026.

- **GigaAM v3 вместо Whisper.** Plain RNNT считывает слова, E2E-модель ставит пунктуацию и регистр. Модель всегда в памяти: нет ожидания загрузки, нет выгрузки в простое, нет галлюцинаций на шуме. Whisper убран из установщика.
- **Тихая речь.** Записи с пиком ниже −24 дБ усиливаются статически перед распознаванием.
- **Первое и последнее слово.** Pre-roll 0,5 с отсчитывается от момента нажатия (метка времени из хука), хвост после отпускания адаптивный (0,25–0,9 с), захват WASAPI с буфером 20 мс.
- **Кнопка.** Дребезг Mouse 5 гасится (70 мс), watchdog хука не даёт ложных отпусканий, короткий тап не показывает ошибку.
- **Старт записи и капсула.** Нажатие во время распознавания предыдущей фразы начинает новую запись; тексты вставляются по порядку в свои окна. Появление капсулы 90 мс, звук и «можно говорить» строго после реального старта захвата. Анимации следуют частоте монитора.
- **Автозапуск.** Если звуковая служба Windows ещё не готова, приложение ждёт микрофон и не закрывается.
- **Установщик.** Единое фирменное окно без системных диалогов: одна страница настроек, прогресс, готово. Остатки Whisper при обновлении удаляются, запущенное приложение закрывается штатно, запуск после установки не падает с кодом 740.
- **Стенд.** `--asr-eval` и `scripts/eval-asr.py` сравнивают конфигурации на ваших записях ([оценка](../models/EVALUATION-3.2.md)).
