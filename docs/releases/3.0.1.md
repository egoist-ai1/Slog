# Слог 3.0.1

Дата: 07.10.2026. Исправление и полировка 3.0.0.

- **Волна капсулы переделана**: вместо расплывчатой ленты с эхо-слоями чёткий спектр: 44 тонких столбика, светлые торцы, падающие пики, тонкий контур, ось в тишине. Диск микрофона полностью лаймовый с чёрной иконкой.
