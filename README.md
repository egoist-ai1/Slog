**Слог** записывает речь по удержанию кнопки, распознаёт её на вашем компьютере и вставляет готовый текст в активное поле: в редактор, терминал, мессенджер, браузер. Звук и текст не уходят в сеть, аккаунта и телеметрии нет.

## Что внутри

- **GigaAM v3** (Сбер) — модель, обученная именно на русской речи. Слова считывает plain RNNT, а пунктуацию и регистр определяет вторая модель по самому звуку. Работает на процессоре, видеокарта не нужна.
- **Модель всегда готова.** Она загружена в память с запуска, поэтому между нажатием и началом записи нет ожидания, а распознавание фразы занимает около 140 мс.
- **Тихая речь.** Очень тихие записи (пик ниже −24 дБ) поднимаются одним статическим коэффициентом перед распознаванием: слабые согласные и окончания перестают теряться. Обычная громкость не затрагивается.
- **Начало и конец фразы.** Запись начинается за 0,5 с до нажатия (звук уже копится в буфере), а после отпускания продолжается, пока затухает речь: от 0,25 до 0,9 с. Первое и последнее слово не обрезаются.
- **Капсула со спектром голоса**: 44 столбика с падающими пиками, чёрная капсула, один акцент (лайм). Появляется за 90 мс, анимации идут с частотой вашего монитора (до 144 Гц) и отключаются настройкой Windows «уменьшить движение».
- **Новая фраза во время распознавания прошлой.** Можно сразу диктовать дальше: тексты вставляются по порядку, каждый в своё окно.
- **Кнопка мыши** (по умолчанию Mouse 5) принадлежит Слогу и не доходит до других программ. Дребезг кнопки гасится. В играх она проходит как обычно.
- **Автозапуск и микрофон**: «Запускать вместе с Windows» включается в настройках. Если звуковая служба при загрузке Windows ещё не готова, Слог ждёт и подключается сам; микрофон тоже подключается, когда появляется устройство.
- **Словарь** названий и терминов с защитой от ложных замен, голосовые команды («запятая», «новая строка»), нормализация чисел.

## Установка

1. Скачайте `Slog-Setup-3.2.0-win-x64.exe` из [релиза](https://github.com/egoist-ai1/Slog/releases/latest) (около 450 МБ: приложение, .NET и модели внутри).
2. Запустите установщик. Он не требует прав администратора и обновляет предыдущую установку, сохраняя настройки.
3. Поставьте курсор в поле ввода, удерживайте **Mouse 5** (или **Ctrl + Alt + Space**), говорите, отпустите.

Установщик не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение.

| Диск | около 1 ГБ |

## Измерения

Измерено на 110 записях автора (русская речь, команды, русский с английскими названиями, быстрая речь, числа). Это один голос и один микрофон, поэтому цифры показывают порядок, а не гарантию. Словарь настраивался по тем же записям, поэтому на новых фразах ошибок может быть больше.

| Доля ошибок в словах | GigaAM v3 (Слог 3.2) |
|---|---:|
| Чистая русская речь | 3,2% |
| Быстрая речь | 7,8% |
| Числа | 0,8% |
| Голосовые команды | 20,8% |
| Русский с английскими названиями | 17,8% |
| Все записи | 12,2% |
| Задержка распознавания (медиана / 95-й процентиль) | 139 / 191 мс |

Тихая речь (та же запись, ослабленная на 30 дБ): без поддержки громкости 15,3% ошибок, в Слоге 3.2 — 12,5%.

Whisper large-v3-turbo в Слоге 3.0–3.1 давал на этих записях меньше ошибок в английских названиях (11,9% против 17,8%), но дольше отвечал (около 200 мс), выгружался из памяти в простое и придумывал текст на шуме. Слог 3.2 вернулся на GigaAM по выбору автора: русская речь и скорость важнее английских названий. Полный разбор конфигураций: [docs/models/EVALUATION-3.2.md](docs/models/EVALUATION-3.2.md).

Что не помогло и не включено: точные fp32-веса (ошибки 13,4%, в 1,5 раза медленнее), расширенный поиск beam4 (14,1%), дополнительная тишина в конце записи, автоматическая регулировка громкости. Честную оценку на вашем голосе даёт инструмент `--corpus-record` (см. [tests/corpus](tests/corpus/README.md)).

## Сборка из исходников

```powershell
dotnet build .\Egoist.Voice.sln -c Release
dotnet test  .\Egoist.Voice.sln -c Release
# установщик: portable → installer (нужен Inno Setup из dotnet tool manifest)
pwsh .\scripts\Build-CompactPortable.ps1 -OutputDirectory .\artifacts\slog-3.2.0\portable
pwsh .\scripts\Build-CompactInstaller.ps1 -StagingDirectory .\artifacts\slog-3.2.0\portable -Build
```

Для portable-сборки нужны восемь файлов весов GigaAM v3 (650 090 519 байт) в `artifacts/Russian-2.4.2-resource-verified/portable/Models/Speech/` (или путь через `-InstalledModelsRoot`). Скрипт проверяет размер и хеши и ничего не скачивает.

Сравнение конфигураций распознавания на своих записях: `Egoist.Voice.exe --asr-eval <папка корпуса> <out.json>` и `scripts/eval-asr.py`.

## Приватность

Запись, распознавание и вставка идут локально. Журнал не содержит ни аудио, ни распознанного текста. История последних записей выключена по умолчанию.
